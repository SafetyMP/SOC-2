KNOW WHAT A RESULT MEANS

Three checks, with explicit limits.

CTRL-CHG-001

Branch protection and force-push settings

Inspect the default branch’s protection settings. A pass does not prove every change used a pull request or that privileged bypass is impossible.

CTRL-CHG-002

Required reviews and status checks

Check the configured approving-review count and required checks. A pass does not prove reviews happened or checks succeeded for each change.

CTRL-CHG-008

Active GitHub Actions workflow

Observe an active workflow under .github/workflows/. Its presence does not prove deployment reproducibility or successful runs.

Unreadable or unsupported settings are missing evidence. Unevaluated controls never count as passing. Planning notes do not change a policy verdict or create a waiver.

FROM YOUR OWN CHECKOUT

Collect. Inspect. Plan. Reassess.

Install Python, PyYAML, OPA, and the GitHub CLI, then follow the setup guide. Use the private report path printed by the first command.

To resume a saved review and its notes on startup, pass the exported review.json to the same --report option. Failed results stay failed.

Assess one repository

python3 scripts/assess_github.py --repo OWNER/REPO

Open your report or exported review locally

python3 scripts/serve_workspace.py \
  --report /absolute/path/report.json
